# GEMINI.md

Ngữ cảnh dự án cho Gemini CLI & Google Antigravity nằm ở **[AGENTS.md](AGENTS.md)** — đọc file đó trước mọi tác vụ.
File này cố ý mỏng để tránh trùng lặp; mọi quy ước, bản đồ thư mục và luật bất biến đều ở `AGENTS.md`.

- Dự án dùng pnpm workspace. Xem lệnh chạy web và kiểm tra trong [README.md](README.md).
- Dự án sử dụng cấu hình Agent Skills chuẩn tại `.agents/skills/`.
- Tuân thủ quy trình phương pháp luận **Superpowers** (`using-superpowers`, `brainstorming`, `systematic-debugging`, `verification-before-completion`).
- Quy trình Spec Kit qua `.specify/` và các skills `speckit-*`.
